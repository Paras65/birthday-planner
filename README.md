# 🎉 ToonWish - Kid's Birthday Cartoon Showtime & Family Wish Wall 🎂

A magical, interactive birthday web app where family members can submit selfies decorated with funny cartoon stickers and write heartfelt wishes. On the birthday, animated cartoon characters take the stage, holding the family members' photos, and speak out the wishes in lively voices with cake cutting, candle blowing, confetti, and a grand dance party!

---

## 🌟 Key Features

1. **📲 Shareable WhatsApp Invite Link**: Generate unique celebration rooms for any kid with a 1-click WhatsApp share link.
2. **🤳 Interactive Selfie Decorator**: Family members can upload or snap a photo and drag-and-drop funny party stickers (Party Hat 🥳, Cool Goggles 🕶️, Crown 👑, Superhero Mask 🦸, Bunny Ears 🐰, Clown Nose 🤡, Bowtie 🎀).
3. **🎭 6 Animated Cartoon Presenters**:
   - 🐱 **Mimi The Kitty** (Sweet, bubbly kitten)
   - 🐻 **Bhalu Dada** (Friendly, cuddly giant teddy bear)
   - 🤖 **Robo Chintu** (Cool synthesized robot)
   - 🦸 **Super Veer** (Heroic champion with cape)
   - 👑 **Pari The Fairy** (Sparkling gentle fairy)
   - 🦖 **Dino Rex** (Playful roaring dino)
4. **🎙️ Natural Indian Speech & Lip-Sync**: Cartoons speak wishes with animated mouth movement and fun Hindi dialogue intros.
5. **🎂 Act 1: Cake Cutting & Candle Blowing**: 3D Birthday cake with candles matching the kid's age. Tap or blow into the phone mic to extinguish candles with realistic smoke and cheering applause!
6. **🎪 Act 2: Grand Theater Stage**: Velvet curtains open, spotlight shines, and cartoons present family wishes.
7. **💖 Kid's Real-Time Reactions**: Kids can tap `🤗 Tight Hug`, `😘 Flying Kiss`, or `✋ High-Five` to send love back.
8. **🕺 Act 3: Grand Finale Dance Party**: All 6 cartoons dance together while family selfies float in balloons that pop when clicked!
9. **📖 Memory Scrapbook**: Printable digital photo album compiling all family selfies and messages for lifelong memories.

---

## 🚀 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Start the server
npm start
```

Open your browser at:
`http://localhost:30001`

---

## ☁️ Deployment (Render.com)

1. Connect this repository to [Render.com](https://render.com/).
2. Select **Web Service**.
3. Settings:
   - **Build Command**: `npm install`
   - **Start Command**: `node server.js`
4. Deploy! Your permanent live URL will be active in 2 minutes.
